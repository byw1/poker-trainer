# Poker Trainer

Preflop open-raise drills for 6-max cash. Get a hand, fold or raise, see the range.

Live: https://poker-trainer-6max.lovable.app

## Run locally

```bash
npm install
npm run dev
```

## Keyboard

- F fold / C call / R raise
- Space or Enter next hand
- ? charts / G glossary

## Charts

v1 training set for 6-max 100bb cash RFI. Frequencies (~13/18/26/44/40%) match commonly published GTO opening-range summaries such as PokerPro's preflop strategy and equivalent 6-max cash charts. Exact hand lists are this project's starting set, not a solver dump.
